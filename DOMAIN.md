# Jonglock Platform Domains

## UAT

- Platform app: `https://platform.zonedevnode.com` or assigned UAT host
- Platform API: `https://jonglockapi.zonedevnode.com/platform`

## Production

- Platform app: `https://platform.jonglock.com`
- Platform API: `https://api.jonglock.com/platform`

## Environment Variables

```bash
VITE_API_BASE_URL=https://api.jonglock.com/platform
```

Use UAT values for UAT builds and Production values for production builds.
